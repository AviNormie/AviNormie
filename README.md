## Featured work

### 🧠 Cyted — AI visibility platform

Shows a business how its brand appears when people ask AI assistants for recommendations. It generates buyer-intent prompts, runs them across multiple LLMs, and analyses mentions, sentiment, competitors, and positioning.

- Live product with 3+ clients
- Multi-model LLM querying with automated prompt generation and response evaluation
- Redis + BullMQ workers so large query batches run in the background with retries

**Stack:** Next.js · React · Node.js · TypeScript · Redis · BullMQ · OpenAI · Claude · Gemini

🔗 [Live](https://cyted-neon.vercel.app/) · [Case study](https://avicodes.tech/blogs/cyted-ai-visibility)

### 📈 StockFlow — real-time market data infrastructure

A distributed stock market platform built around an event-driven pipeline: ingest market data, process it through Kafka, cache state in Redis, and stream it to clients over WebSockets.

- Event-driven microservices in Go
- Low-latency WebSocket streaming with Redis caching
- Metrics, dashboards, and distributed tracing with Prometheus, Grafana, and OpenTelemetry
- Containerised and Kubernetes-ready

**Stack:** Go · Gin · Kafka · Redis · PostgreSQL · WebSockets · Docker · Kubernetes

🔗 [Live](https://stock-flow-liard.vercel.app/) · [API docs](https://stock-flow-liard.vercel.app/api/docs) · [Case study](https://avicodes.tech/blogs/stockflow-trading-platform)

### 🎓 Workpunkt — student management SaaS

A production platform for international student admissions, used daily by the client's team and students. Project lead and engineering manager on a 2000+ commit codebase: architecture decisions, sprint planning, code reviews, and hands-on development.

- Multi-role workflows for students, agents, counsellors, and admins
- Application, document, and status tracking with role-based access
- React Native Android app published on Google Play

**Stack:** Next.js · PostgreSQL · Prisma · Docker · React Native

🔗 [Website](https://www.workpunkt.com/) · [Android app](https://play.google.com/store/apps/details?id=com.workpunkt.app) · [Case study](https://avicodes.tech/blogs/workpunkt-saas)

### 🌐 Influmojo — brand and influencer marketplace

A production marketplace that connects brands and creators, built for web and mobile at the same time.

- Real-time chat, campaign management, and secure payment flows
- Authentication and role-based access for brands and creators
- Shared backend serving a Next.js web app and a React Native mobile app

**Stack:** Next.js · React Native · Node.js · NestJS · PostgreSQL · Prisma · Socket.IO

🔗 [Live](https://influmojo.com/landing) · [Case study](https://avicodes.tech/blogs/influmojo-marketplace)

### 📊 Sapphire Broking — trading platform

Production brokerage software. Joined as lead frontend developer on the trading dashboards, then moved to the backend team to build Go APIs and exchange integrations.

- NSE and BSE exchange API integrations in Go
- Low-latency backend services for trading data
- Trading dashboards and client portals with TradingView charts

**Stack:** Next.js · TypeScript · Go · TradingView

🔗 [Website](https://www.sapphirebroking.com/) · [Broker Terminal demo](https://broker-terminal.vercel.app/watchlist) · [Case study](https://avicodes.tech/blogs/sapphire-broking-systems)
